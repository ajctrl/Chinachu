# 設定画面と保存

「設定フォーム」では表示・録画保存・通知・接続詳細を日本語で編集できます。
フォームで扱わない項目は「JSON編集」で変更でき、フォーム保存時にも保持します。
画面上部の「サーバー設定を保存」の隣にある「JSON編集」で切り替えます。
JSON編集中は同じボタンが「設定フォームに戻る」になります。
切り替えでは未保存の変更を引き継ぎます。JSONの構文が不正な場合は、修正するまでフォームへ切り替えません。
読み込んだ設定が不正なJSONの場合も、元のテキストをJSON編集に表示して修復できます。
修復時も入力検証・更新競合の検出を行い、修復前のテキストをバックアップします。

Mirakurun接続先はHTTPとUnixソケット（`http+unix://` および旧形式 `http://unix:`）に対応します。
MirakurunのHTTPS接続には対応していません。GotifyのURLはHTTP・HTTPSの両方を使用できます。

## ブラウザの表示設定

予約済み画面と設定画面の「番組説明を表示」は共通の設定です。
初期値は非表示で、有効にすると説明を最大3行表示します。説明がない番組には空欄を追加しません。
初期状態では行クリックで既存の番組詳細へ移動します。「詳細」ボタンからは常に番組詳細を開けます。

設定は同じオリジンの `localStorage` の `chinachu.reserves.showDescription` に即時保存します。
同じブラウザの別タブとも同期し、`config.json` には書き込みません。
保存がブラウザに拒否された場合はスイッチの隣に理由を表示します。

### 予約一覧のクリック動作

設定フォームの「表示」→「予約一覧のクリック動作」で選択します。

- **詳細を開く（初期値）**：従来どおり行クリックで番組詳細を開きます。
- **スキップを切り替える**：行を左クリックすると確認なしでスキップ／解除します。番組詳細は各行の「詳細」ボタンから開けます。手動予約の行は詳細を開きます。

変更は `chinachu.reserves.clickAction` としてこのブラウザに即時保存し、別タブとも同期します。
連続した操作は順番に送信し、処理中の同じ番組への重複クリックは無視します。
成功時は通知に「元に戻す」を表示します。失敗時は理由を通知します。
右クリックメニューからの既存操作も引き続き使えます。

## サーバー設定

フォーム・JSON編集のどちらも、保存前に共通の設定定義で値を検証し、APIでも再検証します。
フォームで未設定の項目は、編集しない限り設定ファイルに追加しません。
保存前に変更項目と再起動の必要性を表示します。サービスの再起動は自動では行いません。
共通除外ルールは「ルール」画面から編集し、別ファイルの `excludes.json` に保存します。
変更は次回の予約計画から反映されます。移行方法は [共通除外の説明](auto-exclusion.md) を参照してください。

保存は次の順序で行います。

1. 読み込み時のリビジョンと現在の設定を比較します。不一致なら HTTP 409 で保存を中止します。
2. `config.json` と同じディレクトリに一時ファイルを書き込み、ファイルを同期します。
3. 直前の設定を同じく一時ファイルに書き込み、`config.json.bak` に置き換えます。
4. 設定が途中で変わっていないことを確認し、一時ファイルを `config.json` にアトミックに置き換えます。

バックアップは1世代です。設定とバックアップの所有者・グループ・アクセス権を引き継ぎます。
書き込み・バックアップ・置き換えに失敗した場合、設定を変更せず、画面に失敗した段階とエラーコードを表示します。
設定ファイルだけでなく、そのディレクトリへの書き込み権限も必要です。
共通除外ルールの更新にも同じ保存処理を使い、バックアップ先は `excludes.json.bak` です。
共通除外ルールの保存では `config.json` と `config.json.bak` は変更しません。

APIで保存する場合は、`GET /api/config.json` の `ETag`（引用符を除いた値）を、
`PUT /api/config.json` の `revision` パラメーターとして `json` と一緒に渡します。
リビジョンがない保存は HTTP 428 になります。保存成功時には新しい `ETag` が返ります。
同一WUIプロセスでの保存は順番に処理します。外部エディターや複数のWUIプロセスからの同時書き込みは避けてください。

この変更を導入した後は、新しい保存処理を読み込むためWUIサービスを再起動し、ブラウザを再読み込みしてください。
